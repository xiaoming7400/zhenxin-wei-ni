# female-intimacy-coach

“真心为你”的独立亲密关系沟通 Skill。面向成年人，关注女性体验并尊重个体差异，不假定性别决定欲望、偏好或角色。

## 跨平台使用

普通聊天工具不一定识别 SKILL.md 的目录结构。跨平台请使用同目录的 `UNIVERSAL-PROMPT.md`，其中已合并全部规范、参考资料、工作流和虚构示例，无需依次加载文件。

| 使用方式 | 操作 |
| --- | --- |
| ChatGPT、Claude、Gemini 或其他支持文本输入的助手 | 将 UNIVERSAL-PROMPT.md 全文粘贴到新会话，再提出问题 |
| 支持 Markdown 附件的聊天工具 | 上传 UNIVERSAL-PROMPT.md，并发送下方启动语 |
| 支持自定义助手或知识库的平台 | 将通用文件作为指令或知识文件，要求助手按其规范处理咨询 |
| API 或本地模型前端 | 将通用文件放入该工具支持的系统指令或初始上下文，再传入用户问题 |

启动语：

> 请读取 UNIVERSAL-PROMPT.md，按其中的规范担任“真心为你”亲密关系沟通助手。先确认是否能完整读取文件，再处理我的问题。问题是：……

这些方式依赖平台实际支持的附件、指令长度和上下文容量；没有在各平台逐一实测，也不保证完全相同的回答。上传 ZIP 不代表平台会自动解压并加载资料。若附件无法读取，可粘贴通用文件全文；超出长度限制时分段发送，全部发送后再开始咨询。

通用文件是当前资料的合并快照。在完整项目中，修改分散资料后运行 `python scripts/build_release.py` 自动同步；单独持有技能包时需自行同步。普通聊天中的反馈不会自动改写文件或永久保存。

## Codex 使用

将整个文件夹放入个人技能目录，例如 ~/.codex/skills/female-intimacy-coach，保留所有相对路径。在新会话中请求：

> 使用 $female-intimacy-coach，帮我讨论伴侣之间的欲望差异，给一段自然、不施压的表达。

入口为 SKILL.md。支持聊天复盘、关系分析、性沟通、BDSM 边界讨论和反馈更新。内容属于一般健康教育，不是个体诊疗或具体性行为操作教程。

## 数据与持续更新

只分析主动提供或明确指定的数据。原始记录保留在本地，公开包不包含联系人、聊天内容或个人偏好档案。本技能无需固定电脑路径，也不依赖父项目的数据脚本。

消息统计和相邻对话对只是定位线索，不能当作高质量训练样本或真实意图的证明。

按照 workflows/interaction-review.md 核对反馈、检查反例并更新资料。只有实际保存的内容才跨会话保留；该流程不训练模型参数，也不自动访问网络或推送远程仓库。
